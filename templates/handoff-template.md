## 실제 Azure 구성

`azure-resource-visualizer`가 생성한 Mermaid 또는 문서 링크를 둔다. 설계값과 실제 조회값의 차이를 설명한다.

## 실제 Kubernetes 구성

Deployment, Pod, Service, EndpointSlice, readiness와 내부 DNS 검증 결과를 기록한다. `port-forward` 결과는 로컬 접근 결과로만 기록한다.

## 검증과 문제 해결
